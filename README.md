## 05 / HOW I THINK ABOUT AI

> **Model the process before you call the model.**

I don't start with:

*"Where can we add AI?"*

I start with:

```text
What does the person do today?
        ↓
What is repetitive?
        ↓
What requires judgement?
        ↓
What can deterministic software handle?
        ↓
Where does the model actually add value?
```

The goal isn't another chatbot.

The goal is removing work.

---

## 06 / ENGINEERING PRINCIPLES

**Retrieval first.**
Ground answers in real data instead of model memory.

**Fail out loud.**
A visible failure is better than a silent automation doing the wrong thing.

**Type the boundary.**
LLM output becomes application data only after validation.

**Measure it.**
Production AI needs evaluation, not just impressive demos.

**Own the ambiguity.**
If there isn't a specification, write one.
